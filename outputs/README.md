# Teams Task Calendar for Windows

`teams-calendar-app.zip` is the complete source package for the local Teams notification calendar. It has no Google Cloud integration or cloud billing.

## Install

1. Extract `teams-calendar-app.zip` to a folder you can keep.
2. Make sure Node.js 20 or newer and Windows Developer Mode are installed/enabled.
3. Open the extracted `teams-calendar-app` folder in PowerShell and run:

   ```powershell
   Set-ExecutionPolicy -Scope Process Bypass
   .\prepare-local.ps1
   ```

4. If Windows shows a notification-access prompt, allow it. The setup creates **Teams Calendar** shortcuts on the desktop and in Windows Startup, then opens the app. It will start automatically after you sign in to Windows. If Lively Wallpaper is installed, setup adds the calendar wallpaper to its library and reapplies it after the local server is ready at sign-in.

The app reads the Windows notifications generated by Microsoft Teams on this PC. It captures the Teams desktop/PWA notification source, turns text with a recognized date into suggested tasks or events, and lets you review before adding them. The calendar UI follows the dark green portfolio design already selected.

## Limits

The app only sees Teams messages that Windows and Teams actually surface as notifications. Muted chats and messages without a toast are not available to the Windows listener. The browser calendar does not open automatically at startup; open it from the desktop widget when needed. Notifications and calendar data stay on this PC; calendar entries use browser local storage. See the package's `README.md` for removal and implementation details.
